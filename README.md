# AI-Powered Market Research Scraper

[![Vercel Deployment](https://img.shields.io/badge/Deployment-Vercel-black?style=for-the-badge&logo=vercel)](https://market-research-scraper.vercel.app/)
[![React](https://img.shields.io/badge/Frontend-React-blue?style=for-the-badge&logo=react)](https://reactjs.org/)
[![Node.js](https://img.shields.io/badge/Backend-Node.js-green?style=for-the-badge&logo=nodedotjs)](https://nodejs.org/)
[![Gemini AI](https://img.shields.io/badge/AI-Gemini-orange?style=for-the-badge&logo=google-gemini)](https://deepmind.google/technologies/gemini/)

A sophisticated web research tool that automates data extraction and leverages advanced AI (Gemini and Groq) to provide deep insights from any website.

## Features

- **Automated Scraping**: Efficiently extracts relevant data using Cheerio and Axios.
- - **AI-Driven Insights**: Powered by Google Gemini and Groq for intelligent analysis of scraped content.
  - - **Modern UI**: Built with React for a fast, responsive user experience.
    - - **Seamless Deployment**: Fully optimized for Vercel.
     
      - ## Tech Stack
     
      - | Category | Technology |
      - | :--- | :--- |
      - | **Frontend** | React, CSS3, HTML5 |
      - | **Backend** | Node.js, Express.js |
      - | **AI/ML** | Google Gemini AI, Groq SDK |
      - | **Utils** | Axios, Cheerio |
     
      - ## How it Works
     
      - 1. **Input**: Provide a website URL and research goals.
        2. 2. **Scrape**: The system crawls the site and extracts raw text data.
           3. 3. **Analyze**: AI models process the data to find patterns and answers.
              4. 4. **Result**: Receive a comprehensive research report.
